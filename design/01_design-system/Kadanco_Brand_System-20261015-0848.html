Brand system

The colour and Fira Sans brand used on kadanco.com. One token set drives colour, type, spacing and every component.

Foundations

Colour

Ink and beige grounds carry the brand; blues mark Product, signal lime and orange carry Sales and Marketing.

Foundations

Department colours

Each department owns one hue. Kept here as the single reference, since this mapping had drifted between notes.

Mapping: Product = Blue #3B38DF · Marketing = Lime #DAFF02 · Sales = Lilac #B2B1FF · Accent/PLG = #7270FF. Orange #FE572A is reserved for the CTA, not a department.

Using the tokens

Change a value once in tokens.css / tokens.json → every build follows. This page reads the same tokens.

:root{
  --kd-font-sans:"Fira Sans", ui-sans-serif, system-ui, sans-serif;
  --kd-radius:5px;  --kd-control-h:45px;
  --kd-ink:#201E1F;     --kd-beige-1:#F3F0EB;  --kd-blue-2:#3B38DF;
  --kd-signal-1:#DAFF02; --kd-signal-2:#FE572A; --kd-lilac:#B2B1FF;
}
Security: publish only built CSS to production. Keep this styleguide and the token source behind auth — never in the public web root, and strip any real placeholder data before sharing the link.
